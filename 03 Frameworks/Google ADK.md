# Google ADK

- Agents are either `LlmAgent` (reasoning) or deterministic "workflow agents": `SequentialAgent`, `ParallelAgent`, `LoopAgent` ([[S33 adk_docs|33]]).
- Deployment: `adk deploy` to the Agent Engine runtime ([[S35 gcp_agentengine|35]]); Cloud Run also documents ADK hosting ([[S34 cloudrun_docs|34]]).
- Repository: 22,198 stars, Apache 2.0 ([[S29 github2026meta|29]]).
