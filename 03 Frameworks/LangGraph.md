# LangGraph

- "A low-level orchestration framework and runtime for long-running, stateful agents" focused on durable execution, streaming and human-in-the-loop ([[S44 langgraph_docs|44]]).
- LangChain is the higher-level agent framework built on top of it; Deep Agents is the harness layer ([[S44 langgraph_docs|44]], [[S45 langchain_products|45]]).
- Use it for low-level control and long-running stateful workflows ([[S45 langchain_products|45]]).
- Repository: 44,882 stars, MIT, pushed 13 November 2026 ([[S29 github2026meta|29]]).

**Interpretation.** Choose it when you need to draw the control flow yourself and resume after failure. See [[Framework landscape]], [[Durable execution]].
