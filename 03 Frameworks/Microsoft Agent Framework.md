# Microsoft Agent Framework

- "The direct successor" to Semantic Kernel and AutoGen, created by the same teams ([[S51 msaf_docs|51]]).
- Combines AutoGen's agent abstractions with Semantic Kernel's enterprise features (session-based state, type safety, middleware, telemetry) and adds graph-based workflows for explicit multi-agent orchestration ([[S51 msaf_docs|51]]).
- Repository: 14,656 stars, MIT ([[S29 github2026meta|29]]). The AutoGen repository remains online with 61,800 stars ([[S29 github2026meta|29]]).

**Recommendation.** New projects in the Microsoft stack should start here, not on AutoGen. See [[Framework landscape]].
